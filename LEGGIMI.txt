STUDIO COLARUSSO — ISTRUZIONI

Il sito è un progetto SEPARATO dall'e-commerce: cartella propria, repository GitHub
proprio, progetto Vercel proprio, dominio proprio.

1) VEDERLO SUL COMPUTER
   Estrai lo zip in una cartella nuova (es. Documenti/Siti/studio-colarusso)
   e fai doppio clic su index.html.

2) GITHUB
   github.com → New → nome: studio-colarusso → Create repository
   → "uploading an existing file" → trascina TUTTO il contenuto della cartella → Commit changes.

3) VERCEL
   vercel.com → Add New… → Project → studio-colarusso → Import
   → Framework Preset: Other → Deploy. Ottieni studio-colarusso.vercel.app.

4) IL GESTIONALE (per aggiungere e modificare le opere)
   Indirizzo: il-tuo-sito/admin/   (es. studio-colarusso.vercel.app/admin/)
   Serve una "chiave" GitHub, da creare una volta sola:
   github.com → foto in alto a destra → Settings → Developer settings
   → Personal access tokens → Fine-grained tokens → Generate new token
   - Nome: Gestionale Colarusso · Scadenza: 1 anno
   - Repository access: Only select repositories → studio-colarusso
   - Permissions → Contents → Read and write
   - Generate token → copia la chiave e incollala nel gestionale.
   Nel gestionale: Utente GitHub = il tuo nome utente, Repository = studio-colarusso, Ramo = main.

   Cosa puoi fare: aggiungere opere (la foto viene scontornata e ridimensionata
   da sola), modificare titolo/anno/misure/tecnica/genesi, scegliere le opere in
   evidenza e quella in apertura, spostarle, eliminarle; modificare contatti,
   social e testi. Alla fine premi "Pubblica sul sito": in circa un minuto il
   sito si aggiorna da solo.
   La chiave è personale: non condividerla. Se la perdi, eliminala su GitHub e creane un'altra.

5) DOMINIO
   Progetto studio-colarusso su Vercel → Settings → Domains → aggiungi il dominio.
