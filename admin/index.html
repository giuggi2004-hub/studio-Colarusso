Come ottengo la chiave di accesso?
  1. Su github.com clicca la tua foto in alto a destra → Settings.
  2. In fondo a sinistra: Developer settings → Personal access tokens → Fine-grained tokens.
  3. Generate new token. Nome: "Gestionale Colarusso". Scadenza: 1 anno.
  4. Repository access → Only select repositories → scegli studio-colarusso.
  5. Permissions → Contents → Read and write.
  6. Generate token, copia la chiave e incollala qui. Non condividerla con nessuno.
