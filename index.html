Attiva l'archivio dei messaggi

Per vedere qui i messaggi serve collegare un piccolo archivio gratuito al progetto (una volta sola):

  1. Su Vercel apri il progetto studio-Colarusso → scheda Storage.
  2. Create Database (o Connect Database) → scegli Upstash → Redis → piano gratuito.
  3. Collegalo al progetto studio-Colarusso (tutti gli ambienti) → Connect.
  4. Vai in Deployments → sull'ultimo "…" → Redeploy. Fatto: i nuovi messaggi compariranno qui.

Nel frattempo i messaggi continuano ad arrivare alla tua email.
